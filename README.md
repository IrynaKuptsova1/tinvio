# Tinvio

Адаптивная верстка макета Figma на HTML, CSS и JavaScript.

Запуск из папки проекта:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. Сборка и установка зависимостей не нужны.

Разметка находится в `index.html`, стили — в `index.css`, поведение вкладок,
мобильного меню и слайдера — в `index.js`. SVG встроены в разметку; крупные
изображения находятся в `public`, шрифты — в `fonts`.

Форма проверяет заполнение полей. Для отправки заявок требуется подключение
серверного обработчика.
